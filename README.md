#### 🔨 Projeto em destaque

**[API PetShop](https://github.com/Diogoeugenio9/PetShop.API)** · TCC
API REST em ASP.NET Core (.NET 8) desenvolvida do zero ao deploy para gestão de pet shops:

- API publicada no **Azure App Service**, com banco no **Azure SQL Database**
- Aplicação containerizada com **Docker** no ambiente de desenvolvimento
- Atende várias lojas com isolamento de dados, autenticação JWT e perfis separados para administrador e cliente
- Agendamento online que impede reservas no mesmo horário e conclusão automática dos atendimentos no servidor
- Entity Framework Core (Code First e Migrations), Repository Pattern, camada de serviços e AutoMapper

Também desenvolvo o **BarberFlow**, sistema de gestão para barbearias com API em .NET e front-end em Angular ([BarberFlow.Web](https://github.com/Diogoeugenio9/BarberFlow.Web)).
